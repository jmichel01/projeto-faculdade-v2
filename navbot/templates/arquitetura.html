2. Diagrama de Sequência (UML — Fluxo de Controle, Fila FIFO e Pilha LIFO)

Demonstra a sequência de chamadas entre o Morador (Navegador), o Controlador Flask (app.py), o Validador de Dados (validadores.py), a Fila FIFO / Pilha LIFO (estruturas.py) e o Banco de Dados SQLite (banco.py). 

sequenceDiagram
    autonumber
    actor Morador as Morador (Navegador)
    participant Flask as Controlador Flask (app.py)
    participant Val as Validador (validadores.py)
    participant Fila as FilaAutomacao (FIFO)
    participant Pilha as PilhaComandos (LIFO)
    participant DB as BancoSmartHome (SQLite)

    Morador->>Flask: POST /geral/ar (temperatura_geral = "20")
    Flask->>Val: validar_numero_inteiro("20", "Temperatura", 16, 28)
    Val-->>Flask: Retorna int(20)
    Flask->>DB: listar_por_categoria("ar")
    DB-->>Flask: Lista objetos ArCondicionado

    loop Para cada ArCondicionado da casa
        Flask->>Fila: enfileirar(ar, temp=20, ligado=True)
    end

    loop Enquanto Fila não está vazia (FIFO)
        Flask->>Fila: desenfileirar()
        Flask->>Pilha: empilhar(estado_antigo do aparelho)
        Flask->>DB: atualizar_dispositivo(id_disp, True, 20.0, "Frio")
    end

    Flask->>DB: registrar_log(usuario, perfil, "Sincronizou todos os Ar em 20°C")
    Flask-->>Morador: Redireciona para Painel atualizado (HTTP 200)

    Note over Morador,DB: Caso o morador clique em "Reverter Alteração (LIFO)"
    Morador->>Flask: POST /pilha/desfazer
    Flask->>Pilha: desempilhar()
    Pilha-->>Flask: Retorna último estado salvo (topo da pilha)
    Flask->>DB: atualizar_dispositivo(id_disp, ligado_antigo, valor_antigo, modo_antigo)
    Flask->>DB: registrar_log(usuario, perfil, "DESFEZ AÇÃO (Pilha LIFO)")
    Flask-->>Morador: Restaura estado anterior na tela

3. Modelagem do Banco de Dados Relacional (DER — SQLite3)

O arquivo de banco de dados smarthome2050.db possui 5 tabelas relacionais normalizadas que armazenam usuários, cômodos, dispositivos da casa, estoque interno da geladeira e histórico de auditoria. 

erDiagram
    COMODOS ||--o{ DISPOSITIVOS : "possui (comodo_codigo)"
    USUARIOS ||--o{ HISTORICO_EVENTOS : "registra (usuario)"

    USUARIOS {
        INTEGER id PK
        TEXT username UK
        TEXT nome_exibicao
        TEXT senha_hash
        TEXT perfil
    }

    COMODOS {
        TEXT codigo PK
        TEXT nome
        TEXT descricao
        INTEGER ordem
    }

    DISPOSITIVOS {
        INTEGER id PK
        TEXT comodo_codigo FK
        TEXT nome
        TEXT categoria
        INTEGER ligado
        REAL valor_num
        TEXT modo_atual
        TEXT detalhe_extra
        INTEGER restrito_admin
    }

    ITENS_GELADEIRA {
        INTEGER id PK
        TEXT nome_item
        INTEGER quantidade
        TEXT unidade
        TEXT categoria_item
        TEXT validade_status
    }

    HISTORICO_EVENTOS {
        INTEGER id PK
        TEXT data_hora
        TEXT usuario
        TEXT perfil
        TEXT acao
    }
Tabela SQLite Chave Primária Colunas Principais Finalidade no Sistema
usuarios id (INTEGER PK) username, nome_exibicao, senha_hash, perfil Autenticação com hash PBKDF2 e controle de permissão (administrador vs comum).
comodos codigo (TEXT PK) nome, descricao, ordem Cadastro dos 5 ambientes da casa (SALA, COZ, SUITE, QUARTO2, EXTERNA).
dispositivos id (INTEGER PK) comodo_codigo (FK), nome, categoria, ligado, valor_num, modo_atual, restrito_admin Estado persistente dos 23 aparelhos (TVs, Ar, Geladeira, Som, Luzes, Portas e Câmeras).
itens_geladeira id (INTEGER PK) nome_item, quantidade, unidade, categoria_item, validade_status Estoque interno de alimentos e bebidas da Geladeira Inteligente.
historico_eventos id (INTEGER PK) data_hora, usuario, perfil, acao Trilha de auditoria de todos os comandos executados ou bloqueados.
