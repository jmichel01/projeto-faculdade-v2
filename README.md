# Central de Controle da Casa Inteligente 2050

Aplicação web em Python (Flask e SQLite) para controle residencial completo por cômodo (Sala, Cozinha, Suíte, Quarto de Hóspedes e Área Externa), permitindo gerenciar Smart TVs, ar-condicionado, iluminação, som ambiente, fechaduras digitais, câmeras de segurança, estoque interno da geladeira inteligente e comandos gerais para toda a casa.

## Link para Utilizar

- **Acesso Online:** https://navbot-2050.vercel.app

## Como Executar Localmente

```bash
pip install -r requirements.txt
python run.py
```

Acesse `http://127.0.0.1:8000` no navegador.
